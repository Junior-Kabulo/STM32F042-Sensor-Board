# STM32F042 ENS210 Development Board

A compact 4-layer development board based on the STM32F042K6T6 microcontroller and the ENS210 temperature and humidity sensor.

---

## Overview

This project is a custom 4-layer PCB designed for learning, prototyping and embedded firmware development using the STM32F0 family.

The board integrates power regulation, programming interface and environmental sensing in a compact form factor.

---

## Hardware

### Microcontroller

- STM32F042K6T6
- ARM Cortex-M0
- 32 KB Flash
- 6 KB SRAM
- USB Full-Speed Device
- I²C
- SPI
- UART

### Sensor

- ENS210
- Temperature measurement
- Relative humidity measurement
- I²C interface

### Power Supply

- External Power Connector
- NCP1117-3.3 V LDO regulator
- Decoupling capacitors

### Debug Interface

- SWD Programming Header
- NRST Push Button

### Clock

- External Crystal Oscillator

- Dedicated Power Plane
